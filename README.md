# panchang-ts

Pure TypeScript Hindu Panchang calculations. Zero native dependencies.
Works offline in React Native (Hermes), Node.js, and browsers.

> 🚧 Under development. See the implementation plan for details.

## Install

```bash
npm install panchang-ts
```
