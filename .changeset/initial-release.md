Initial release of panchang-ts v0.1.0.

Pure TypeScript Hindu Panchang calculations: Tithi, Nakshatra, Yoga, Karana, Vara,
Sunrise/Sunset, Rahu Kalam, Gulika Kalam, Yamaganda, and Abhijit Muhurta.

- Daily mode: full sunrise-to-sunrise day with multi-element transitions
- Instant mode: element active at an exact UTC moment
- 3 ayanamsa systems: Lahiri, Raman, KP
- 3 languages: English, Sanskrit (Devanagari), Hindi
- React Native / Hermes compatible (zero native deps)
- Validated against DrikPanchang.com for 15+ date/city fixtures
